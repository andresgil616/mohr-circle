# Mohr Circle

Librería de Python para el cálculo y visualización del Círculo de Mohr aplicado a Ingeniería Civil.

## Descripción

Este proyecto tiene como objetivo desarrollar una librería de Python que permita calcular y visualizar los principales parámetros del Círculo de Mohr para un estado plano de esfuerzos.
